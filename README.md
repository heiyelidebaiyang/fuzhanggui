# fuzhanggui

富掌柜风格的餐饮交易看板与点餐开单页，纯静态单文件页面，无需后端。

## 页面

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 交易看板 | `/` 或 `/index.html` | 登录 → 销售总览 / 订单列表 / 销售账单 / 商品分析 / 数据说明 |
| 点餐开单 | `/order-pad.html` | 独立点餐终端，开单后数据存浏览器本地，回到看板自动合并 |

## 数据

- 订单 4,768 笔、菜品明细 32,946 行、114 个 SKU，区间 2026-03-18 ~ 2026-11-24
- 数据在生成 HTML 时已固化进页面，页面本身不发任何请求（图表库 ECharts 走 jsDelivr CDN）
- 点餐开单产生的新单只写入浏览器 `localStorage`，不涉及任何真实商户云端

## 声明

纯演示与分析用途，页面中的商户号、终端号、门店名仅用于界面还原，与真实交易系统无关。

## 本地打开

克隆后直接双击 `index.html` 即可；点餐页与看板需在同一目录，才能共用本地存储。
